# 2026-10-07

## light-image-tool 项目初始化

从空骨架(main.c 仅空壳、jpeg.h 仅注释、README 占位)补齐了可工作的纯 C 图像中间件基础:

- `src/light_image.h` + `src/core/image.c`: 核心抽象 `LITImage`(行优先、4 字节行对齐、RGB(A) 顺序), 创建/销毁/像素访问/错误码。
- `src/core/bmp.c/.h`: 纯 C 实现 BMP 编解码, 支持 8 位灰度 / 24 位 / 32 位, 处理小端与行对齐、自底向上/top-down。
- `src/core/ops.c/.h`: 灰度化、水平/垂直翻转、顺时针 90° 旋转(均生成新图像, src 只读)。
- `src/jpeg/include/jpeg.h`: 仅补全接口声明(`lit_jpeg_load`/`lit_jpeg_save`), 实际 JPEG 编解码待实现。
- `src/main.c`: CLI(`info` / `to-gray` / `flip-h` / `flip-v` / `rot90`)。
- `Makefile`: `make` 产出统一二进制 `bin/lit`; `make libs` 产出 `lib/liblitcore|liblitbmp|liblitops`(.so/.dll)。
- `README.md` 补全构建/使用/结构/路线图; 新增 `.gitignore`。

注意: 本环境无 C 编译器(gcc/clang/cl 均不可用), 代码未经本地编译验证, 需用户在装有编译器的机器上 `make` 验证。

## 编译与测试(已验证)

- 发现机器装有 **MSVC Build Tools 18**(`cl.exe`)与 **Windows SDK 10.0.26100.0**。
  - 沙箱禁止从 Bash 调用 `cmd.exe`, 故改用 PowerShell 设置 INCLUDE/LIB/PATH 后直接调用 `cl.exe` 编译成功, 产出 `bin/lit.exe`(164KB)。
  - 新增 `build_msvc.bat` 作为 Windows 上的便捷编译脚本(内部 `vcvars64.bat` + `cl`)。
- 新增 `test/test_bmp.py`: 纯标准库生成已知 BMP, 调 `lit` 各子命令后独立解析输出校验(统一放在 `test/` 文件夹下)。
- 测试结果: **13/13 全部 PASS** —— info(RGB/GRAY/RGBA 维度/格式/stride)、to-gray 亮度公式、flip-h/flip-v、rot90(维度+像素)、8 位灰度往返、32 位 RGBA 往返均正确。
- README 增加 MSVC 构建说明与测试说明; `.gitignore` 忽略 `test/out/`。
